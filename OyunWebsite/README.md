# Meteor Avcisi Oyun Odevi

Bu klasorde HTML, CSS ve JavaScript kullanilarak hazirlanan "Meteor Avcisi" isimli canvas tabanli arcade oyun bulunmaktadir.

## Prompt ve Hazirlama Sureci

1. Yapay zeka ajanina tarayicida calisan, uzay temali ve canvas kullanan basit bir oyun istedigimi belirttim.

2. Prompt icinde oyuncunun uzay gemisini saga sola hareket ettirmesi, meteorlara ates etmesi, skor kazanmasi ve can sisteminin olmasi gerektigini yazdim.

3. Arayuz icin skor, can, seviye, baslatma ekrani, duraklatma butonu ve mobil kontrol tuslari eklenmesini istedim.

4. JavaScript tarafinda oyun dongusu, carpismalar, seviye artisi ve tus kontrolleri yapay zeka tarafindan olusturuldu.

5. Son olarak renkleri, hizlari ve oyun metinlerini duzenleyerek daha oynanabilir hale getirdim.

## Ornek Prompt

```text
HTML5 canvas ile uzay temali bir arcade oyun yap. Oyunun adi Meteor Avcisi olsun. Oyuncu bir uzay gemisini yonetsin, gelen meteorlara ates etsin, yildizlari toplasin, skor kazansin ve 3 cani olsun. Oyun baslatma ekrani, skor paneli, seviye sistemi, duraklatma butonu ve mobil kontrol tuslari bulunsun. HTML, CSS ve JavaScript dosyalarini ayri hazirla.
```
