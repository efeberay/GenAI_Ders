# Sudoku Egitici Oyun Odevi

Bu klasorde HTML, CSS ve JavaScript ile hazirlanan egitici Sudoku oyunu yer almaktadir. Oyun; zorluk secimi, ipucu, hata sayaci, sure ve kontrol etme ozellikleri icerir.

## Prompt ve Hazirlama Sureci

1. Yapay zeka ajanina sadece oyun degil, ayni zamanda kurallari ogreten bir Sudoku uygulamasi istedigimi belirttim.

2. Prompt icinde kolay, orta ve zor seviye secenekleri; ipucu butonu; hata sayaci; sure takibi ve kontrol etme ozelliginin bulunmasini istedim.

3. Arayuzun egitici olmasi icin yan panelde kural aciklamalari ve secilen hucreye gore yonlendirme metinleri olmasini soyledim.

4. JavaScript tarafinda tahta olusturma, rakam girisi, dogruluk kontrolu ve ipucu mantigi hazirlandi.

5. Son asamada renkleri, butonlari ve oyun durum mesajlarini duzenleyerek kullanimi daha anlasilir hale getirdim.

## Ornek Prompt

```text
HTML, CSS ve JavaScript kullanarak egitici bir Sudoku oyunu hazirla. Oyunda kolay, orta ve zor seviyeler olsun. Kullanici hucre secip rakam girebilsin, hatalar sayilsin, sure tutulsun, ipucu alabilsin ve "Kontrol Et" butonu ile cevaplarini denetleyebilsin. Yan panelde Sudoku kurallari ve ogretici aciklamalar bulunsun. Tasarim modern, temiz ve mobil uyumlu olsun.
```
