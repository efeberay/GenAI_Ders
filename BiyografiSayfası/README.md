# Biyografi Sayfasi Odevi

Bu klasorde Efe Beray Bicer icin hazirlanan kisisel biyografi web sitesi bulunmaktadir. Site; kisa tanitim, sosyal medya baglantilari, Spotify alani, bilgisayar sistemi bilgileri ve 3D model goruntuleme bolumlerinden olusur.

## Prompt ve Hazirlama Sureci

1. Yapay zeka ajanina kisisel bir web sitesi hazirlamak istedigimi, sitenin tek sayfa ve modern gorunumlu olmasi gerektigini soyledim.

2. Prompt icinde "kisa hayatim", sosyal medya kartlari, bilgisayar sistemim ve Spotify oynatici gibi bolumlerin bulunmasini istedim.

3. Gorsel farklilik icin 3D arac modelinin sayfada `model-viewer` ile gosterilmesini istedim.

4. Kod tarafinda HTML, CSS ve JavaScript dosyalarinin ayri tutulmasini; menunun mobilde acilir kapanir sekilde calismasini belirttim.

5. Olusan taslagi kendi bilgilerime gore duzenledim, baglantilari ekledim ve siteyi yayinlanabilir hale getirdim.

## Ornek Prompt

```text
Benim icin modern ve tek sayfalik bir kisisel biyografi sitesi olustur. Site koyu temali, mobil uyumlu ve akici animasyonlara sahip olsun. Bolumler: giris alani, 3D model goruntuleme, Spotify oynatici, kisa hayatim, bilgisayar sistemim ve sosyal medya baglantilari. HTML, CSS ve JavaScript dosyalarini ayri hazirla. Tasarim sade ama dikkat cekici olsun.
```
