# GenAI Ders Odevleri

Bu repo, yapay zeka destekli uretim sureciyle hazirlanan ders odevlerini klasorler halinde icerir. Her klasor ayri bir odev olarak duzenlenmistir ve ilgili klasorun icinde proje dosyalari ile prompt/aciklama README dosyasi bulunur.

## Klasorler

1. `AMYO broşür`: Ayancik MYO tanitim brosuru.
2. `BiyografiSayfası`: Kisisel biyografi web sitesi.
3. `cv`: CV hazirlama calismasi.
4. `OyunWebsite`: Meteor Avcisi isimli canvas oyun.
5. `SirketWebSite`: Samsung konulu cok sayfali tanitim sitesi.
6. `SudokuEgiticiOyun`: Egitici Sudoku web oyunu.

## Genel Kullanim

Web sitesi ve oyun odevleri ilgili klasordeki `index.html` dosyasi tarayicida acilarak incelenebilir. PDF ve DOCX dosyalari ise belge olarak teslim amacli eklenmistir.
