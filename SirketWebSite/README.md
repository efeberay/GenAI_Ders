# Samsung Tanitim Web Sitesi Odevi

Bu klasorde Samsung markasini tanitan cok sayfali bir web sitesi calismasi bulunmaktadir. Site; ana sayfa, hakkimizda, urunler, surdurulebilirlik ve iletisim sayfalarindan olusur.

## Prompt ve Hazirlama Sureci

1. Yapay zeka aracina bir teknoloji sirketi icin cok sayfali tanitim sitesi hazirlamasini istedim.

2. Prompt icinde Samsung temasini kullanarak ana sayfa, hakkimizda, urunler, surdurulebilirlik ve iletisim sayfalarinin olmasini belirttim.

3. Tasarim icin modern, sade, beyaz agirlikli, urun gorselleriyle desteklenen ve mobil uyumlu bir yapi istedim.

4. Yapay zekadan HTML sayfalarini ayri ayri, ortak CSS ve JavaScript dosyalariyla hazirlamasini istedim.

5. Daha sonra metinleri, gorselleri, menu baglantilarini ve sayfa gecislerini kontrol edip odeve uygun hale getirdim.

## Ornek Prompt

```text
Samsung icin resmi siteye benzemeyen, odev amacli cok sayfali bir tanitim web sitesi hazirla. Sayfalar: Ana Sayfa, Hakkimizda, Urunler, Surdurulebilirlik ve Iletisim. Tasarim modern, mobil uyumlu, sade ve teknoloji odakli olsun. Urun kartlari, hero alani, navigasyon menusu ve footer bulunsun. HTML dosyalarini ayri, CSS ve JavaScript dosyalarini ortak hazirla.
```
